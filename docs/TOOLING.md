# Инструменты репозитория

Заказчику нужен только готовый XML и скрипт сертификата.
Python-скрипты — для тех, кто меняет YAML.

Подробности команд: [BUILD_AND_INSTALL.md](BUILD_AND_INSTALL.md).
Что проверяют тесты: [TESTING.md](TESTING.md).

## Что получает заказчик

`scripts/build.py` склеивает YAML из `src/templates` и записывает
`dist/zabbix-6.0/CSP_all_templates.xml`. Этот файл импортируют в Zabbix.
Отдельные YAML-фрагменты импортировать нельзя.

## Дата и версия экспорта

В `src/templates/00-group.yaml` два разных поля:

| Поле | Что это | Менять? |
| --- | --- | --- |
| `version: '6.0'` | Формат XML Zabbix. Импортёр читает его | Только если появится отдельный профиль под другой engine |
| `date: '2025-11-06T08:35:37Z'` | Служебная метка «когда выгрузили XML». На опрос и метрики не влияет | Не нужно. Сборщик её не проставляет |

Дата не версия шаблона и не версия CSP. Zabbix при экспорте из UI ставит текущее
время; здесь она **заморожена**, чтобы повторная сборка давала те же байты
и не засоряла git. Другая дата сама по себе ничего не переключает.

## `scripts/build.py`

Единственная команда сборки. Читает `profiles/zabbix-6.0.yaml`, склеивает
исходники, проверяет внутренние ссылки, атомарно пишет XML.
`--check` сравнивает уже лежащий `dist` с тем, что получилось бы сейчас,
и ничего не записывает.

## `scripts/template_io.py`

Это не отдельная утилита и не то, что запускает заказчик.
Библиотека сборщика: какие поля YAML/XML мы поддерживаем, строгие типы,
перевод дерева в XML. `build.py` вызывает её сам.

Если в шаблон нужно новое поле экспорта, его сначала добавляют в `SCHEMAS`
здесь, иначе сборка отвергнет неизвестный ключ.

## `scripts/inventory.py`

Справочник по **нашему** XML: UUID, кто на кого ссылается (master, формулы,
графики, LLD). Нужен, когда правите метрику и хотите увидеть потребителей.
Не опрашивает CSP и не запускает Zabbix.

```sh
.venv/bin/python scripts/inventory.py --format markdown
```

## `scripts/validate.py`

Проверяет, что собранный XML нашего подмножества схемы читается и что
внутренние ссылки сходятся.
